What it does today

Built for Indian families. Honest about what it will not do.

  • Policies

    Store PDFs, track renewals, and ask a question about one file you own.

  • Health vault

    Records, vitals, and medications — organized for the household, never diagnosed.

  • Emergency

    A card you can share, plus SOS via SMS/Share. Location only while you use it.

  • Hospitals

    Nearby map and official insurer cashless links. We do not verify empanelment.

  • Claims organizer

    A checklist of typical India health-claim papers, linked to files already in your vault. You still file with the insurer.
